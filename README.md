# claude-gpt

GPT-модели через авторизацию Codex/ChatGPT в привычном Claude Code CLI и его расширении для VS Code.

Личный эксперимент для macOS Apple Silicon. Реализацию написал ИИ-агент в Codex по моим требованиям; я проверял её в своей работе и возвращался с ошибками. [История проекта для Хабра](docs/habr.md).

**Статус: экспериментальная интеграция с закреплёнными версиями, а не универсальный клиент.** Требуется собственная действующая авторизация Codex через ChatGPT и доступ к соответствующим моделям. Проект не является официальной интеграцией OpenAI или Anthropic.

## Что запускается

```text
Claude Code CLI / расширение VS Code
             ↕ Messages API: JSON или SSE
claude-gpt — временный HTTP-шлюз на 127.0.0.1
             ↕ Responses через библиотеки Codex
OpenAI — авторизация пользователя через ChatGPT
```

Обёртка запускает шлюз на случайном локальном порту со случайным bearer-токеном, передаёт настройки дочернему Claude Code и при обычном завершении закрывает шлюз вместе с ним. Постоянного демона, LaunchAgent или отдельного приложения нет. Временный HTTP-сервер **есть** и работает внутри процесса обёртки.

VS Code использует настройку `claudeCode.claudeProcessWrapper`: вручную поднимать сервер перед открытием расширения не требуется. Установщик меняет эту настройку с резервной копией, устанавливает бинарник и `/codex-usage`. Бинарники Claude Code и файлы расширения не переписываются.

Историю и выполнение инструментов продолжает вести Claude Code. Мост переводит сообщения, tool calls/results, изображения и события ответа. К OpenAI уходят системные инструкции, история и результаты инструментов, включённые Claude Code в модельный запрос.

## Возможности

- Каталог GPT-моделей загружается при запуске через библиотеки Codex; при ошибке предусмотрен кэш. Новые совместимые записи могут появляться без правки списка вручную.
- Стандартное и расширенное окна представлены отдельными вариантами. Значения берутся из каталога, оценка длины запроса выполняется локально.
- По умолчанию выбирается расширенный Terra, если он есть в каталоге, затем стандартный Terra, затем первый доступный вариант.
- Spark включается, если доступен в каталоге; отдельные квоты видны в usage, когда сервис их возвращает.
- Уровни effort сопоставляются с поддерживаемыми моделью значениями. `max` выбирает наиболее высокий доступный семантический уровень; передаваемое значение может отличаться, см. [src/effort.rs](src/effort.rs).
- Поддерживаются потоковый и обычный JSON-ответы Messages API, продолжение истории через штатные аргументы Claude Code.
- `/codex-usage` показывает лимиты подписки без запроса к модели. Сбросы указаны в UTC; данные кэшируются на минуту. Штатные оценки стоимости Claude Code не являются показаниями биллинга OpenAI.
- Экспериментальный stdio MCP-инструмент `imagegen` запускается тем же бинарником, сохраняет PNG в `generated_images/claude-gpt/` и возвращает путь. Доступность генерации зависит от сервиса и аккаунта.

## Перед сборкой

Проверенная конфигурация:

| Компонент | Закреплённая версия |
|---|---|
| Платформа | macOS arm64 |
| Claude Code CLI | 2.1.258 |
| Claude Code for VS Code и embedded CLI | 2.1.263 |
| Codex | 0.153.4 |
| Rust | 1.95.0 |
| Исходники Codex | `985641272869835d01d025ed2a218fbbce35fa9f` |

Нужны Rust/rustup, инструменты сборки macOS, собственные установки Claude Code и VS Code extension и уже выполненный вход Codex через ChatGPT. API-key auth мост отвергает. О различиях способов входа: [официальная документация](https://learn.chatgpt.com/docs/auth).

Пути пока закреплены под конкретную раскладку установок. `src/paths.rs` ожидает:

```text
~/.local/share/claude/versions/2.1.258
~/.vscode/extensions/anthropic.claude-code-2.1.263-darwin-arm64/
/Applications/ChatGPT.app/Contents/Resources/codex
~/.codex/
~/Library/Application Support/Code/User/settings.json
```

Установка Codex только через другой пакетный менеджер не заменяет ожидаемый путь автоматически. Нужны также совпадающие SHA-256 из `compatibility.json`. Одного совпадения номера версии недостаточно. Проект не устанавливает и не распространяет эти сторонние приложения.

На другой комбинации версий требуется адаптация путей и повторная проверка контрактов. Простая замена хэшей отключит смысл проверки и сама по себе не обеспечит совместимость.

## Сборка и установка

```sh
git clone https://github.com/arahisman/claude-gpt.git
cd claude-gpt
cargo fmt --check
cargo test --locked --all-targets
cargo build --locked --release
target/release/claude-gpt install
```

Транзитивные Git-зависимости тоже закреплены. Первая сборка скачивает исходники и может занять заметное время.

После установки выполните `Developer: Reload Window` в VS Code. После обновления самого bridge перезагрузка окна тоже нужна: уже запущенные процессы продолжают исполнять прежнюю версию.

```sh
~/.local/bin/claude-gpt
~/.local/bin/claude-gpt --continue
~/.local/bin/claude-gpt --resume SESSION_ID
~/.local/bin/claude-gpt usage
```

В расширении выбирайте GPT-модель в списке моделей; usage вызывается командой `/codex-usage`.

## Проверка и откат

```sh
~/.local/bin/claude-gpt doctor
~/.local/bin/claude-gpt doctor --live
target/release/claude-gpt repair
~/.local/bin/claude-gpt uninstall
```

`doctor` проверяет установленную комбинацию и получает каталог по сети, но не запускает inference. `doctor --live` дополнительно делает минимальный модельный запрос, расходующий квоту. `repair` нужно запускать **новым собранным бинарником**, чтобы установить именно его. `uninstall` восстанавливает прежнюю конфигурацию, проверяя последующие пользовательские изменения.

Контрактные тесты используют локальные шлюзы, временные файлы и тестовый транспорт. Три live-теста помечены `ignore`: для них нужны установленные приложения и подписка, и они расходуют квоту. Команда запуска явно выбранного набора:

```sh
cargo test --locked --test live_acceptance -- --ignored
cargo test --locked --test real_claude_contract -- --ignored
```

## Ограничения

- Это частичная реализация Messages API для нашего сценария Claude Code. Не все поля и инструменты Anthropic перенесены. Например, `max_tokens` и `stop_sequences` сейчас не транслируются в исходящий Responses-запрос.
- Локальная оценка токенов приблизительная; изображения имеют фиксированную оценку. Она не заменяет подсчёт сервиса. Автокомпакт и продолжение длинных мультимодальных сессий требуют дополнительного тестирования.
- Если запрос не помещается в выбранный стандартный вариант, gateway может использовать подходящий расширенный вариант той же модели из каталога. Это влияет на размер отправляемого контекста и потенциально на расход квоты. При отсутствии подходящего варианта возвращается ошибка; автоматического сокращения истории в gateway нет.
- HTTP-запрос ограничен 32 MiB. Автоматического уменьшения изображений или очистки старых вложений нет.
- Собственного OpenAI web-search адаптера здесь нет. Наличие WebSearch/WebFetch в Claude Code не доказывает их работоспособность через этот мост.
- Совпадение списка моделей, effort и окон не гарантирует полного совпадения поведения с приложением Codex.
- Закреплённые версии защищают от запуска на непроверенных локальных файлах. Они не замораживают серверную сторону OpenAI; изменения сервиса могут потребовать доработок.

Не добавляйте в issues файлы авторизации, историю чатов или полные пользовательские настройки. Для воспроизведения ошибки подходят версии, обезличенный текст ошибки и минимальный пример.
